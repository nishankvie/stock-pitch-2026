# Stock pitch data: LONG DWS / SHORT Ashmore

Data, valuation maths and charts for the BFC/BVH Stock Pitch Competition 2026 one-pager.
Everything was compiled on 22 Oct 2026. Prices are closes from that day.

## Rerun

```bash
cd stock_pitch_data
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/01_prices.py   # 5y prices + Yahoo snapshot  -> data/prices_*.csv, data/peers_yahoo_raw.csv
.venv/bin/python scripts/02_peers.py    # peer quotes + consensus EPS  -> data/peers.csv
.venv/bin/python scripts/03_calc.py     # P/E, yields, scenarios, grids -> calc/*.csv (prints the summary)
.venv/bin/python scripts/04_charts.py   # PNG (300 dpi) + SVG           -> charts/
```

Scripts 01, 02, 03 and 04 must run in that order. Rerunning 01 and 02 refreshes prices and consensus, so the numbers in
`calc/` will change. `SUMMARY.md` and `CHECKS.md` are snapshots from 22 Oct 2026 and are not regenerated.

## Files

| Path | What it is |
|---|---|
| `data/theme.csv`, `data/dws.csv`, `data/ashmore.csv` | **Hand-curated** from primary sources (ETFGI releases, DWS quarterly statements/half-year report, Ashmore RNS/annual report, Bundestag/FMA pages). One row per figure: `metric, value, unit, period, source_url, accessed, notes`. `NOT FOUND` is written where a figure could not be verified. |
| `data/peers.csv` | Generated by `02_peers.py` from Yahoo Finance (via yfinance). |
| `data/prices_dws.csv`, `data/prices_ashm.csv` | 5y daily OHLC from yfinance. `Close` is **not** dividend-adjusted (DWS paid EUR 6.10 in Jun 2024, visible as a drop). Ashmore is in pence. |
| `calc/` | Outputs of `03_calc.py`: scenarios, sensitivity grids, Ashmore history ratios, `summary.csv` (every final number with formula and source). |
| `charts/` | Hook, long, short charts and optional 5y price charts. |
| `CHECKS.md` | Every value from the brief compared with what was found. |
| `SUMMARY.md` | The numbers to use on the one-pager. |

## Definitions worth knowing

- **Forward P/E** = price / consensus EPS for the company's *current, not yet reported* fiscal year (Yahoo "0y").
  Year ends differ (DWS/Amundi Dec, Ninety One/Liontrust/Polar Mar, Ashmore Jun), see `fy_basis` in `peers.csv`.
- Yahoo gives EPS for LSE stocks in GBP while prices are in pence; `02_peers.py` converts EPS to pence.
- **Ashmore core EPS** = company's *adjusted diluted EPS* (excludes FX translation, seed-capital items and related tax).
- **Ashmore market cap** uses 650.8m shares (712.7m issued less 61.9m held by the Employee Benefit Trust), because
  EPS is calculated on shares excluding own shares and the EBT shares get no dividend. The company's "73p excess capital per share" is
  calculated on 712.7m issued shares. On the 650.8m basis it is 80p (see `CHECKS.md`).
- Scenario inputs (growth, multiples, EPS) are variables at the top of `scripts/03_calc.py`.
- PDFs and RNS pages were downloaded to a scratch folder for text extraction and are not stored here. Every figure links to its source URL.
